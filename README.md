## About me

Full-stack developer at **TeamMove**, a B2B SaaS for sales team management, where I work across the whole product: web, mobile app, back end and database. I'm also studying Software Engineering at UniSATC (class of 2028).

- **Real-time sales campaign engine:** rebuilt one of the product's core modules, merging 5 legacy engines and ~40 hard-coded rules into one configurable engine that serves every account.
- **ERP integration layer:** designed the connector contract that 6 integrations run on (TOTVS, Senior, Movere, Projedata and more).
- **Performance:** took a production PostgreSQL query from ~20 min to 0.6 s, about 2,000× faster.
- **AI workflows:** I run complex multi-agent workflows with Claude Code every day: executable specs, parallel agents in isolated worktrees, review gates, custom skills and MCP.
